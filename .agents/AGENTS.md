# RecDesk Workspace Rules

1. **No `tauri dev`**: Never run `tauri dev` or start the dev server. The user runs it manually.
2. **No binary builds**: Never run `tauri build` or build the executable unless explicitly asked by the user.
3. **No git push**: Never push code to GitHub unless explicitly asked by the user.
4. **Planning mode ("just plan")**: When the user asks to plan or says "just plan", only create/update the plan and wait for approval before making any code changes.
